The Problem & Solution

Vehicle fuel efficiency (Miles Per Gallon - MPG) depends on multiple mechanical specifications. Estimating expected fuel consumption helps drivers and buyers assess automotive economy and performance.

  • Objective: Deliver an intuitive, interactive tool to predict fuel efficiency based on custom vehicle parameters.
  • Data Source: 1974 Motor Trend US magazine dataset (mtcars).
  • Interactive Application: Built with R Shiny, allowing users to manipulate sliders and radio buttons for real-time MPG estimation.

2. The mtcars Dataset & Exploratory Analysis

The mtcars dataset comprises fuel consumption and 10 aspects of automobile design for 32 automobiles (1973–74 models).

3. Predictive Statistical Model

We fit a multivariate linear regression model to compute predicted MPG dynamically inside server.R:

> fit <- lm(mpg ~ hp + wt + factor(cyl) + factor(am), data = mtcars)
> coef(summary(fit))

4. Visualizing Model Performance

The application renders an interactive scatter plot comparing user inputs against historical data:

> ggplot(mtcars, aes(x = hp, y = mpg, color = factor(cyl))) +
+   geom_point(size = 3) +
