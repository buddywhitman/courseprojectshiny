# mtcars MPG Predictor & Performance Explorer

This repository contains the Shiny Application and Reproducible Pitch Presentation developed for the **Coursera Developing Data Products** peer-assessed project.

## Repository Contents

- `ui.R`: User Interface definitions including sliders, radio buttons, plot outputs, and documentation tabs.
- `server.R`: Server logic with reactive linear model prediction, dataset filtering, and dynamic ggplot visualization.
- `index.Rmd`: R Markdown presentation source file.
- `index.html`: Rendered HTML5 5-slide pitch presentation.
